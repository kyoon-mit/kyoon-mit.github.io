## Starting point

Members of our group showed that LLM-based agents can carry out a high energy
physics analysis from start to finish: event selection, background
estimation, uncertainty quantification, statistical inference and paper
drafting.
See [E. A. Moreno, S. Bright-Thonney, A. Novak, D. Garcia, P. Harris, "AI
Agents Can Already Autonomously Perform Experimental High Energy
Physics"](https://arxiv.org/abs/2603.20179) (2026).

## This project

We are working toward a similar design for LIGO: an agent that runs a
gravitational-wave analysis end to end, aimed at anomaly detection. The exact
scope is still being decided.

## First step

Define the dataset and the gravitational-wave benchmarks that agents will be
evaluated on.
